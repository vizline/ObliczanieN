# Obliczanie N

Minimalistyczny, interaktywny przewodnik po analizie mocy i planowaniu liczebności próby w badaniach psychologicznych.

## Uruchomienie lokalne

To statyczna strona bez procesu budowania. Otwórz `index.html` albo uruchom prosty serwer HTTP, np. `python -m http.server 8080`.

## Źródło merytoryczne

Prototyp przygotowano na podstawie podręcznika „Jak duża powinna być moja próba? Analiza mocy a priori i planowanie liczebności próby w badaniach psychologicznych” (Michał Zięba i Mariusz Zięba, wersja z 20 października 2026).

Kalkulator na stronie stosuje przybliżenia asymptotyczne i służy do orientacji. Ostateczne N należy zweryfikować w narzędziu odpowiadającym planowanej analizie.
